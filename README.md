# Кейс

Компания **ООО «Яндекс Крауд»** хочет создать единую BI-систему для мониторинга HR-бренда и репутации работодателя, чтобы управлять воронкой подбора и эффективностью HR-коммуникаций на рынке массового найма и удалённой работы.

## Пользователи
*   HR-директор
*   HR-маркетинг и бренд-команда
*   Рекрутеры (в т.ч. массового подбора)
*   HR-аналитики
*   Руководители направлений
*   Внешние подрядчики по рекрутменту и коммуникациям

## Требования

### Интеграция данных
*   **Внешние источники:**
    *   Сайты отзывов о работодателях (Dreamjob, Otzovik, IRecommend, Avito)
    *   Платформы с вакансиями
    *   Новостной портал VC.ru
*   **Внутренние источники:**
    *   Данные по найму, откликам, бюджетам
    *   Статистика по причинам ухода сотрудников (включая данные партнёра Ancor)

### Построение витрины данных
*   Единые справочники
*   Историчность данных
*   Возможность помесячного и кумулятивного анализа метрик

### Разработка дашбордов для мониторинга
*   Динамики рейтингов и отзывов на всех ключевых площадках:
    *   Общий рейтинг
    *   Условия труда
    *   Коллектив
    *   Доход
    *   Возможности роста и пр.
*   Доли позитивных/негативных отзывов и их влияния на целевые рейтинги
*   Эффективности контента и публикаций на VC.ru и других медиа:
    *   Просмотры
    *   Открытия
    *   Реакции
    *   Комментарии
    *   Репосты
    *   Сохранения
*   Причин ухода сотрудников в разрезе типов причин («зарплата», «карьерный рост», прочее)
*   Показателей массового подбора по рынку:
    *   Отклики
    *   Стоимость отклика
    *   Доля по городам и уровням опыта
    *   Корреляция с бюджетами и NET-вилками

### Ключевые функциональные возможности
*   Отображение ключевых метрик HR-бренда с целевыми значениями рейтингов на dreamjob.ru, Otzovik, IRecommend, Avito (с детализацией по показателям)
*   Поддержка гибкой фильтрации (город, период, компания, опыт кандидата, сегменты сотрудников и т.д.)
*   Обеспечение актуальности данных, близкой к режиму «near real-time», для оперативного реагирования на:
    *   Всплески негативных отзывов
    *   Проседание откликов
*   Реализация всех витрин данных и визуализаций в единой BI-системе (**Yandex DataLens**) с возможностью расширения и подключения новых источников.

## Дополнительный контекст
*   Рынок соискателя уже сформировался. Конкуренция за кандидата и за статус **«Top of mind»** работодателя по атрибуту **«удалённая работа»** очень высокая.
*   **Бизнес-цель** — рост знания HR-бренда, улучшение репутации работодателя и, как следствие:
    *   Улучшение всех показателей воронки подбора
    *   Уменьшение текучести
*   Часть коммуникаций и рекрутинга ведётся через внешних подрядчиков (например, Ancor), поэтому важно сопоставлять их данные с внутренними.
*   Ранее метрики HR-бренда были разрознены по различным отчётам и сервисам, что усложняло управленческие решения и замер эффекта от кампаний.
*   Компания стремится строить решения на собственных технологиях и использовать накопленную экспертизу в данных и аналитике для развития HR-функции.
